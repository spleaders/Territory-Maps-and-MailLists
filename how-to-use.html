How to Use Your Territory Map & Mailing List

A simple, step-by-step guide — no computer experience needed.

1 Getting Started

Someone sent you a link. Tap or click that link.

You'll see a page with your territory's name and one big button:

🗺 Open Interactive Map

Tap that button. It opens right in your web browser (like Chrome, Safari, or Edge) — there is nothing to download or install. It works the same way on a phone, a tablet, or a computer.

2 Two Tabs at the Top

Near the top of the page you'll see two tabs. Tap either one to switch — you can go back and forth as many times as you like:

  • 🗺 Map — shows every address in the territory on a map.
  • 📋 Mailing List — shows the same addresses as a plain list, which can be easier for finding one specific name.

3 Using the Map

Tap on any colored shape on the map to open a small info box for that address. It will show you:

  • The address
  • The resident's name, if one is on file
  • A colored label telling you the status (see the Color Guide below)
  • A 📍 Get Directions link — tap this and your phone will open its map app and give you driving directions straight there.
  • A Mark as Worked checkbox — tap this once you've finished that address, and it will be marked as done.
Good to know: When you mark an address as worked, everyone else using the same link sees it marked too — automatically. You don't need to call or text anyone to let them know.

4 Color Guide

Every address on the map is colored to tell you its status at a glance:

Confident ResidentA name is on file — ready to contact.
Needs ResearchNo confirmed name yet.
VerifiedThe name has been double-checked.
SuspectDouble-check before mailing.
InstitutionA school, church, care facility, etc.
BusinessA business address.
VacantAn empty lot or empty building.
Do Not ContactSkip this address.
Covered by Another TerritorySkip — someone else already has it.
CompletedAlready finished.
Please Do Not Contact: Any address shown in red with stripes is marked Do Not Contact. Please skip these addresses — do not call, mail, or visit them.

5 Using the Mailing List Tab

This tab shows the same addresses as a simple list — handy for finding one specific name or address quickly.

  • Type a name, address, or ID number into the Search box at the top to find it fast.
  • Tap the checkbox next to any row to mark it worked — this is the exact same checkbox as the "Mark as Worked" button on the map.
  • Tap 📋 Share Progress to send an email with the link, along with a note showing how much has been completed so far.

6 Sharing With Others

There are two different "share" buttons, and they do slightly different things:

  • ✉ Share Territory (top of the page) — emails the link itself, so someone else can open the same map and mailing list.
  • 📋 Share Progress (Mailing List tab) — emails the link plus a short note about how much has been completed so far.

That's everything you need to get started. If anything is confusing, just ask whoever sent you this link — they'll be glad to help.
