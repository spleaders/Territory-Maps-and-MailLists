Name and Address Finder

For Fond du Lac and Dodge County addresses.

How to use
  1. Type the House number and Street. Add the Apt, Town or ZIP if you have them.
  2. Tap Find. The answer appears below, and the boxes clear for the next address.
  3. Read the color: green = use the name shown, blue = write "Current Resident", yellow = read the note first, red = not found, check the spelling.
  4. When your list is done, tap Copy list or Download spreadsheet.

Rules of use

  • Names come from public county tax records. They show who owns a property, which is not always who lives there.
  • Use the names and addresses only for letter writing. Don't post or share the lists.
  • When in doubt, write Current Resident.

Questions or problems

Tip: on a phone, tap Share, then "Add to Home Screen" so this opens like an app.
