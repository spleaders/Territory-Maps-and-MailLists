Name and Address Finder

For Fond du Lac and Dodge County addresses.

How to use
  1. Type the house number. Example: 160
  2. Type the street. Example: S Macy St
    Town and ZIP are extra. Fill them in if you know them.
  3. Tap Find.
  4. Look at the color on the left of the answer:
    • Green: write the name shown.
    • Blue: write Current Resident.
    • Yellow: read the note on the card first.
    • Red: not found. Check the spelling.
  5. Next house on the same street? Just type the new number and tap Find again.
  6. All done? Tap Copy list or Download spreadsheet.

Please remember

  • Use these names only for letter writing. Don't share the list.
  • Not sure about a name? Write Current Resident.

Need help?

Want to find names for "Current Resident" houses, or apartments? Tap Advanced above.

How to copy and paste

    Other devices

      Show only people living there now

      On USPhoneBook, use Find on page and search for the phrase shown on the card (like Lives at 160 S Macy). Only current residents light up. Use the up and down arrows to jump between them.

      • Windows: press Ctrl + F, then paste or type the phrase.
      • Mac: press ⌘ Command + F.
      • iPhone / iPad (Safari): tap the Share button (square with an arrow), then Find on Page.
      • Android (Chrome): tap ⋮ (three dots), then Find in page.

      On the other sites:

      • TruePeopleSearch: open the person. Under Current Address it must be your address, with dates up to now.
      • FastPeopleSearch: tap View Free Details. The current address at the top must be your address.

      Find a name for a "Current Resident" house

      1. On the blue card, tap one of the Look up residents buttons. A website opens with the address already filled in.
      2. These sites mix in old and wrong names. Only use a person listed as living there now.
      3. Copy the name, come back here, paste it in Name found, and tap Use.
      4. The letter will say "Name or Current Resident". Changed your mind? Tap Undo.

      Apartments and other buildings with many homes

      1. Check the box Apartment or other multi-unit building, then tap Find.
      2. For a full list of units, tap Email Steve.
      3. Or do it yourself: tap a Look up residents button. For each unit the site shows, type the unit number (and the name, if listed as living there now) and tap Add.
      4. If a website shows #, Apt or Unit after an address you looked up the normal way, it's a building with many homes. Look it up again with the box checked.

      Check a ZIP code

      On a blue card, tap Check this ZIP with the Post Office. The street is copied for you. On the Post Office page, paste it in Street Address, type the town, pick WI, and tap Find.

      Look up many addresses at once

      Tap Paste a whole list instead, paste your addresses (one per line), and tap Find all.

      Put this tool on your home screen

      • iPhone / iPad: tap the Share button (a square with an arrow), then Add to Home Screen.
      • Android: tap the ⋮ menu (three dots), then Add to Home screen.
      • Computer: click the ☆ star at the end of the web address to bookmark it.

      About the names

      • Names come from public county tax records. They show who owns a house, which is not always who lives there.
      • Green means the owner's tax bill goes to that same house, so the owner very likely lives there. It is a strong clue, not a guarantee. It can be wrong if the house sold recently, the owner moved or passed away, or a landlord gets mail there. If it matters, write "Name or Current Resident".
      • Names from people-search websites can be years old. They are marked "unconfirmed".
      • Use names and addresses only for letter writing. Don't post or share the lists.
